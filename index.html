Mini Game Arcade

Welcome! Choose a game and have fun while practising programming.

Games in this project

1. Rock Paper Scissors

A Python console game. Play against the computer and try to win!

File: python/rock_paper_scissors.py

2. Number Guessing Game

A C++ console game. Guess the secret number with hints from the computer.

File: cpp/number_guessing_game.cpp

How to play

  1. Run the Python file to play Rock Paper Scissors.
  2. Compile and run the C++ file to play Number Guessing Game.
  3. Read the README file for complete instructions.

Programming concepts used

  • HTML: headings, paragraphs, sections, articles and lists.
  • Python: variables, input/output, lists, loops, conditions and random numbers.
  • C++: variables, input/output, loops, conditions and random number generation.
