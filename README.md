# Mini Game Arcade

A beginner-friendly mini project created using HTML, Python and C++.

## Games included

### 1. Rock Paper Scissors (Python)
Play against the computer. The computer randomly chooses rock, paper or scissors. The first player to score 3 points wins.

**Run it:**
```bash
python python/rock_paper_scissors.py
```

### 2. Number Guessing Game (C++)
The computer chooses a secret number from 1 to 100. Keep guessing; the game tells you whether your guess is too high or too low.

**Compile it:**
```bash
g++ cpp/number_guessing_game.cpp -o number_guessing_game
```

**Run on macOS/Linux:**
```bash
./number_guessing_game
```

**Run on Windows:**
```bash
number_guessing_game.exe
```

## HTML homepage
Open `index.html` in a web browser to see the project homepage and instructions.

## Concepts used

- **HTML:** headings, paragraphs, sections, articles, lists and basic page structure.
- **Python:** variables, input/output, lists, `while` loop, `if/elif/else`, membership checking and the `random` module.
- **C++:** variables, input/output, `do-while` loop, `if/else`, random number generation and basic arithmetic.
